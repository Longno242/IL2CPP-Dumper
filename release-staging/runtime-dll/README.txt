IL2CPP Dumper runtime DLL (v1.5.0)

Contents:
  dumper-x64.dll  — inject into 64-bit games
  dumper-x86.dll  — inject into 32-bit games

1. Launch the application and wait for IL2CPP to initialize
2. Load the matching DLL into the process
3. Output: Desktop\GameDump

Supports renamed il2cpp exports when normal API resolve fails.
